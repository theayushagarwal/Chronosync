# Website Change Detector - Chrome / Edge Extension

A lightweight browser extension (Manifest V3) to monitor any webpage on your local Change Detector with 1 click.

## How to Install (Takes 15 seconds)

1. Open **Google Chrome**, **Microsoft Edge**, or **Brave**.
2. Navigate to: `chrome://extensions` (or `edge://extensions`).
3. Toggle on **Developer mode** in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the `extension/` folder in this project:
   `c:\Users\ayush\Downloads\change-detector\change-detector\extension`
6. The **Change Detector** icon will now appear in your browser's toolbar!

---

## How to Use

1. Navigate to any webpage you want to monitor (e.g. an e-commerce product page, a flight ticket page, or documentation).
2. Click the **Change Detector** extension icon in your toolbar.
3. The current page's URL and title will be automatically filled in.
4. *(Optional)* Click **"🎯 Click element on page"** to hover and click any specific element (like a price or stock badge) to auto-extract its CSS selector.
5. Click **Start Watching**.
6. That's it! The page is instantly queued in your local Change Detector dashboard on `http://localhost:8000`.
